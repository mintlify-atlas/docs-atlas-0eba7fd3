Compodex gives you composable, accessible React components specifically designed for Pokémon data. Built on top of shadcn/ui and Radix UI primitives, it handles the complexity of type systems, stat visualizations, evolution chains, and sprite rendering — so you can focus on building your app.

## Get up and running

<Steps>
  <Step title="Set up shadcn/ui">
    Compodex requires shadcn/ui with CSS Variables mode. If you don't have a project yet, use [shadcn/create](https://ui.shadcn.com/create) to scaffold one.
  </Step>
  <Step title="Add the Compodex registry">
    Add the registry entry to your `components.json` so you can use shorthand install commands:

    ```json components.json
    {
      "registries": {
        "@compodex": "https://compodex.netlify.app/r/{name}.json"
      }
    }
    ```
  </Step>
  <Step title="Install your first component">
    Use the shadcn CLI to add any Compodex component:

    <CodeGroup>
    ```bash npm
    npx shadcn@latest add @compodex/pokemon-image
    ```
    ```bash pnpm
    pnpm dlx shadcn@latest add @compodex/pokemon-image
    ```
    </CodeGroup>
  </Step>
  <Step title="Use it in your app">
    Import and render the component with your Pokémon data:

    ```tsx
    import { PokemonImage, PokemonSprite, PokemonFallback } from "@/components/compo-dex/pokemon-image";

    export function MyPokemon() {
      return (
        <PokemonImage size="lg">
          <PokemonSprite
            src="https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/25.png"
            alt="Pikachu"
          />
          <PokemonFallback />
        </PokemonImage>
      );
    }
    ```
  </Step>
</Steps>
